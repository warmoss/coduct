== 银行家舍入法讲解

**银行家舍入法** 也称为**四舍六入五成双**, 是一种更科学的舍入方法, 主要用于减少在大量计算中的累积误差.

=== 核心规则

**四舍六入五成双**的完整规则:

. **当舍去位的数字 < 5时** -> 直接舍去

. **当舍去位的数字 > 5时** -> 进位

. **当舍去位的数字 = 5时**(关键规则):

** 如果5后面**有非零数字** -> 进位

** 如果5后面**没有数字或全为0** -> 看前一位:

*** 前一位为**奇数** -> 进位

*** 前一位为**偶数** -> 舍去

=== 示例说明

保留2位小数的情况:

[cols="1,1,1,2"]
|===
|原始值|传统四舍五入|银行家舍入法|解释
|1.234|1.23|1.23|第三位4<5, 直接舍去
|1.236|1.24|1.24|第三位6>5, 进位
|1.2350|1.24|1.24|5后面是0, 前一位3(奇数), 进位
|1.2450|1.25|1.24|5后面是0, 前一位4(偶数), 舍去
|1.2351|1.24|1.24|5后面有非零数字, 进位
|1.2451|1.25|1.25|5后面有非零数字, 进位
|===

=== 数学原理

银行家舍入法基于**统计学原理**:

* 在大量计算中, 传统四舍五入会使结果**系统性偏高**

* 银行家舍入法使舍入误差的**期望值为零**

* 对于中间值5, 一半情况进位, 一半情况舍去, 概率相等

=== 编程实现

Python示例:

[source, python]
----
def bankers_round(value, decimals=0):
    """实现银行家舍入法"""
    from decimal import Decimal, ROUND_HALF_EVEN
    
    # 使用Decimal确保精确计算
    return float(Decimal(str(value)).quantize(
        Decimal('1.' + '0'*decimals), 
        rounding=ROUND_HALF_EVEN
    ))

# 测试
test_values = [1.235, 1.245, 1.234, 1.236, 1.2351]
for val in test_values:
    print(f"{val:.4f} -> {bankers_round(val, 2)}")
----

Java示例:

[source, java]
----
import java.math.BigDecimal;
import java.math.RoundingMode;

public class BankersRounding {
    public static double bankersRound(double value, int decimals) {
        BigDecimal bd = new BigDecimal(Double.toString(value));
        bd = bd.setScale(decimals, RoundingMode.HALF_EVEN);
        return bd.doubleValue();
    }
}
----

=== 应用场景

* **金融计算:** 利息计算、汇率转换

* **统计分析:** 减少数据处理的系统性偏差

* **科学计算:** 需要高精度数值计算的领域

* **工程测量:** 仪器数据采集和处理

=== 与传统四舍五入对比

|===
|特性|传统四舍五入|银行家舍入法
|累积误差|有系统性偏差|误差期望为零
|中间值(5)处理|总是进位|奇进偶不进
|公平性|偏大|更公平
|复杂度|简单|较复杂
|===

=== 注意事项

. **浮点数精度问题:** 计算机中的浮点数有精度限制, 可能影响舍入结果

. **使用场景:** 普通日常计算用传统四舍五入即可, 银行家舍入法主要用于专业领域

. **国际标准:** IEEE 754标准推荐使用银行家舍入法(舍入到最接近的偶数)

银行家舍入法虽然在规则上稍复杂, 但在需要高精度计算和减少系统性误差的场景下, 它提供了更科学、更公平的舍入方案.
