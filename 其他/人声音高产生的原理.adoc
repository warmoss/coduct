== 人声音高产生的原理

人说话或唱歌时, 声音的高低(音高)看似由"嗓子"直接发出, 实际是**呼吸动力, 声带振动, 声道共鸣**三者协作的结果. 本文从物理与生理角度拆解人声音高的产生机制, 并说明音高与音色为何能彼此独立.

参考: <<数学/波的原理讲解.adoc#, 波的原理讲解>>, <<硬件/麦克风原理讲解.adoc#, 麦克风原理讲解>>

=== 基本概念

音高(Pitch):: 人对声音频率高低的主观感知, 与声带振动的**基频**近似对应, 但二者并非线性关系
基频(Fundamental Frequency, F0):: 声带每秒钟开合的周期数, 单位赫兹(Hz), 是决定音高的物理量
声带(Vocal Folds):: 喉内两片由黏膜, 声韧带和声带肌构成的弹性组织, 振动时切割气流发声
声门(Glottis):: 左右声带之间的开口, 是气流从肺部进入声道的通道
声道(Vocal Tract):: 从声门延伸至唇, 鼻的共鸣腔体, 包括咽腔, 口腔和鼻腔
共振峰(Formant):: 声道共振在频谱上形成的能量峰值(通常记为 F1, F2, ...), 决定元音与音色
谐波(Harmonic):: 频率为基频整数倍的分量, 声带振动产生的频谱由一系列谐波构成

=== 音高的物理基础

音高在物理上对应**基频**, 而人耳对频率的感知近似**对数**关系: 频率翻倍, 听感上只升高一个八度.

[stem]
----
f_n = f_0 \cdot 2^{n/12}
----

其中 stem:[f_0] 为基准音频率, stem:[n] 为相隔的半音数. 不足一个半音的音高差异用**音分**(cent)度量:

[stem]
----
\Delta = 1200 \log_2 \frac{f_2}{f_1}
----

人耳可听范围约 stem:[20 Hz] 到 stem:[20 kHz], 而人声基频集中在 stem:[80 Hz] 到 stem:[1100 Hz], 远低于听觉上限. 这一"低基频 + 丰富谐波"的组合, 正是人声信息量的来源.

[cols="2,2,3", options="header"]
|===
| 声部 | 典型音域 | 基频范围

| 男低音(Bass) | E2 - E4 | 约 82 - 330 Hz
| 男高音(Tenor) | C3 - C5 | 约 131 - 523 Hz
| 女低音(Alto) | F3 - F5 | 约 175 - 698 Hz
| 女高音(Soprano) | C4 - C6 | 约 262 - 1047 Hz
|===

日常说话的基频更低: 成年男性约 85 - 180 Hz, 成年女性约 165 - 255 Hz, 儿童约 250 - 400 Hz.

=== 发声器官与动力链路

人声的产生是一条完整的**能量转换链**: 呼吸肌推动肺内气体形成声门下压, 声带在气流作用下自激振动, 把稳定的气流切成准周期脉冲; 声道再对这些脉冲做频谱塑形, 最后由唇鼻辐射到空气中.

----

[鼻腔] as nose
[唇鼻辐射] as lip

lung --> folds : 声门下压
folds --> pharynx : 准周期气流脉冲

pharynx --> nose

note right of folds : 决定音高 f0

@enduml
----

在这条链路中, **只有声带振动频率决定音高**, 其余环节影响音色. 这是理解"同一音高可以唱出不同元音"的关键.

=== 声带如何振动

==== 肌弹性-空气动力学机制

声带不是被拉紧后像琴弦一样被动发声, 而是一个**自激振动系统**(self-oscillation). 经典解释是**肌弹性-空气动力学理论**(myoelastic-aerodynamic theory), 由三种机制共同维持:

* **组织弹性**: 声带被冲开后依靠自身弹性回缩
* **空气动力**: 气流通过狭窄声门时流速增大, 压强降低(Bernoulli 效应), 把声带"吸"回中线
* **黏膜波**: 声带表层黏膜相对深层组织的波动, 是有效振动的标志

[plantuml, "声带的一个振动周期", format=png]
----
@startuml
title 声带的一个振动周期
start
:声门闭合, 声门下压持续升高;
:声门下压超过阈值, 声门被冲开;
:气流加速通过声门;
:声门处压强下降(Bernoulli 效应);
:声带弹性回缩与压差合力使声门闭合;
:气流被阻断, 声门下压再次升高;
stop
@enduml
----

振动一旦建立, 只要声门下压高于**发声阈压**(Phonation Threshold Pressure, 约 0.3 - 0.5 kPa)就能自行维持. 正常说话时声门下压约 0.5 - 1.0 kPa, 大声喊叫可达 2 - 4 kPa.

==== 声带的分层结构

声带由表及里分为**被覆层**(cover)和**体层**(body): 被覆层包含上皮与浅层固有层, 质地柔软; 体层包含声韧带与声带肌, 刚度较高. 两层刚度差异使振动时产生相位差, 形成自下而上的黏膜波.

体-被覆理论(body-cover theory)解释了发声机制的差异: 胸声带动体层一起振动, 假声则主要让被覆层滑动.

==== 频率的决定因素

把声带近似为一根张紧的弦, 其振动频率满足:

[stem]
----
f_0 = \frac{1}{2L}\sqrt{\frac{T}{\mu}}
----

其中 stem:[L] 为有效振动长度, stem:[T] 为张力, stem:[\mu] 为单位长度质量. 换成声带的语言:

* **长度越长, 频率越低**
* **张力越大, 频率越高**
* **质量(厚度)越大, 频率越低**

喉部肌肉正是通过调节这三个量来改变音高:

[cols="2,2,3", options="header"]
|===
| 肌肉 | 作用 | 对基频的影响

| 环甲肌(Cricothyroid, CT) | 拉长, 拉薄声带, 增大张力 | 升高 f0
| 甲杓肌(Thyroarytenoid, TA) | 缩短, 增厚声带, 增大质量 | 降低 f0
| 呼吸肌群 | 调节声门下压 | 压力升高时 f0 略微上升
|===

高音更多依赖**环甲肌主导的拉长变薄**, 低音更多依赖**甲杓肌主导的缩短增厚**. 两种肌肉力量的配比切换, 形成了不同的发声机制.

=== 声源-滤波器模型

==== 模型定义

**声源-滤波器模型**(Source-Filter Model)由 Gunnar Fant 于 1960 年提出, 把人声分解为两个可独立分析的部分:

声源(Source):: 声带振动产生的准周期脉冲串, 其频谱是基频整数倍的谐波, 幅度随频率大致按 -12 dB/oct 衰减
滤波器(Filter):: 声道作为声学共鸣管, 对不同频率有不同放大倍数, 其峰值即共振峰
辐射(Radiation):: 唇端声压辐射带来的约 +6 dB/oct 高频提升

最终语音频谱约等于**声源谐波频谱与声道传递函数的乘积**:

[stem]
----
S(f) = G(f) \cdot H(f) \cdot R(f)
----

其中 stem:[G(f)] 为声源频谱, stem:[H(f)] 为声道传递函数, stem:[R(f)] 为辐射特性.

==== 共振峰与元音

均匀管(一端封闭, 一端开口)的共振频率为:

[stem]
----
F_n = \frac{(2n-1)c}{4L}
----

成年男性声道长度约 stem:[L = 0.17 m], 声速 stem:[c = 343 m/s], 由此得到共振峰间隔约 stem:[500 Hz], 与实测结果吻合. 女性与儿童的声道更短, 共振峰整体上移, 这是相同基频下二者音色仍有明显差异的原因之一.

元音的音色差异主要由前两个共振峰 F1, F2 决定:

[cols="2,3,3", options="header"]
|===
| 元音 | F1 (Hz) | F2 (Hz)

| /i/(衣) | 约 270 | 约 2290
| /e/(诶) | 约 530 | 约 1840
| /a/(啊) | 约 730 | 约 1090
| /o/(哦) | 约 570 | 约 840
| /u/(乌) | 约 300 | 约 870
|===

F1 越低, 舌位越高; F2 越高, 舌位越靠前. 这也是**改变音高而不改变元音**的物理依据: 声源频率变了, 声道的共振结构并未改变.

=== 胸声, 假声与换声

同一副声带能以不同的**振动模式**工作, 称为发声机制(register):

* **胸声(Modal, M1)**: 声带整体振动, 有效质量大, 声音厚实, 基频较低
* **假声(Falsetto, M2)**: 只有声带黏膜边缘振动, 有效质量大幅减小, 基频可升高约一个八度, 音色偏虚
* **哨音(Whistle, M3)**: 声带中部极小区域振动, 频率极高, 常见于女高音炫技

音高上升跨越机制边界时, 需要调整肌肉平衡完成切换, 该位置称为**换声点**(passaggio). 未经训练的换声容易产生音色断裂(brake)或破音.

=== 音高的测量

从录音中提取基频是语音处理的基础任务. 最直观的方法是**自相关**: 寻找波形与自身平移后最相似的延迟, 该延迟即振动周期.

[source,python]
----
import numpy as np

def estimate_f0(x, sr, fmin=60, fmax=1000):
    x = x - np.mean(x)                              # <1>
    corr = np.correlate(x, x, mode="full")[len(x) - 1:]
    corr /= corr[0]
    lo, hi = int(sr / fmax), int(sr / fmin)         # <2>
    lag = lo + int(np.argmax(corr[lo:hi]))
    return sr / lag                                 # <3>
----
<1> 去直流分量, 避免零延迟处的偏置
<2> 把频率范围换算为延迟范围, 缩小搜索区间
<3> 周期转频率

实际工程更常用 YIN 或 pYIN 等改进算法, 它们通过累积均值归一化差分函数抑制自相关的**倍频错误**(octave error).

=== 影响音高的其他因素

* **生理发育**: 青春期喉软骨增大, 声带变长, 男性基频平均下降约一个八度
* **激素水平**: 性激素与甲状腺激素影响声带组织的含水量和黏弹性
* **疲劳与炎症**: 声带水肿使质量增加, 基频下降, 音域变窄
* **情绪与语气**: 兴奋时整体基频抬高, 疑问句句尾常见基频上扬
* **训练**: 歌手通过增强环甲肌力量与声带闭合能力扩展音域

=== 常见误区

* **音高由声带厚薄决定**: 厚度只是质量因素之一, 张力与长度的作用同样关键, 且可动态调节
* **肺活量大就能唱高音**: 气压只提供动力, 超过阈压后继续加压对音高提升有限, 反而增加声带损伤风险
* **假声不振动**: 假声依然是声带振动, 只是振动集中在黏膜边缘, 参与质量更小
* **基频就是音色**: 基频决定音高, 音色由谐波结构与共振峰共同决定

=== 总结

人声音高的产生可归纳为一条链路和一条公式:

* **链路**: 肺部气流 -> 声带自激振动 -> 声道共振塑形 -> 唇鼻辐射
* **公式**: stem:[f_0 \propto \frac{1}{L}\sqrt{\frac{T}{\mu}}], 长度, 张力, 质量共同决定基频
* **分工**: 声源决定音高, 滤波器决定元音与音色, 二者通过声源-滤波器模型解耦
