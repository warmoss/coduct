== 数据库闭包讲解

在数据库理论, 特别是关系数据库中, "闭包"通常指**属性集闭包**. 它是用于规范化(如求候选键、判断范式)的核心工具.

简单来说, 给定一个属性集 stem:[X] 和一组函数依赖 stem:[F], stem:[X] 关于 stem:[F] 的闭包 stem:[X^+], 就是指通过 stem:[F] 中的依赖关系, 能从 stem:[X] 直接或间接推导出的所有属性的集合.

=== 为什么要计算闭包?

计算闭包主要用于解决以下问题:

* **判断是否为候选键:** 若 stem:[X^+] 包含了表中的所有属性, 则 stem:[X] 是一个超键; 若它的任意真子集的闭包都不包含全部属性, 那它就是候选键.

* **判断函数依赖是否成立:** 要检查 stem:[X -> Y] 是否被 stem:[F] 蕴含, 只需看 
stem:[Y] 是否是 stem:[X^+] 的子集.

* **求函数依赖集 stem:[F] 的闭包:** 通过计算所有属性子集的闭包, 可以得出所有隐含的函数依赖.

* **判断范式等级:** 用于分析是否存在部分依赖或传递依赖.

=== 计算算法(逐步推导)

计算闭包的算法非常直观, 可以这样进行:

. **初始化:** 将 stem:[X] 设为结果集 `result` 的初始值.

. **迭代:** 反复扫描所有函数依赖 stem:[A -> B], 如果 stem:[A] 已经是当前 `result` 的子集, 而 stem:[B] 还不是, 就把 stem:[B] 的所有属性加入 `result`.

. **终止:** 直到 `result` 不再变化为止, 这时的 `result` 就是 stem:[X^+].

=== 举个实例

假设有一个关系模式 stem:[R(A, B, C, D, E)], 函数依赖集 stem:[F] 如下:

. stem:[A -> B]

. stem:[BC -> D]

. stem:[D -> E]

现在我们想求属性 stem:[A] 的闭包 stem:[A^+].

* **第一步:** 初始化 `result` = stem:[{A}].

* **第二步:** 扫描依赖, 发现 stem:[A -> B], 左边 stem:[A] 在集合中, 于是加入  stem:[B], `result` = stem:[{A, B}].

* **第三步:** 继续扫描, 发现 stem:[BC -> D], 但此时 `result` = stem:[{A, B}], 不包含 stem:[C], 所以无法触发, 暂时跳过.

* **第四步:** 再次扫描(或继续向后), 此时没有依赖左边完全在集合中的.

* **注意:** 因为没有依赖能引入新属性, 循环结束. 最终 stem:[A^+ = {A, B}].

从这个结果可以看出: **仅凭 stem:[A] 无法推导出 stem:[C], stem:[D], stem:[E]**, 因此 stem:[A] 不是候选键.

=== 再举一个求候选键的例子

还是用上面的 stem:[R(A, B, C, D, E)], 但这次我们求 stem:[(A, C)] 的闭包 stem:[(AC)^+].

* **初始:** `result` = stem:[{A, C}].

* **应用 stem:[A -> B]:** 加入 stem:[B], `result` = stem:[{A, B, C}].

* **应用 stem:[BC -> D]:** 现在集合里有 stem:[B] 和 stem:[C], 满足左边条件, 加入 stem:[D], `result` = stem:[{A, B, C, D}].

* **应用 stem:[D -> E]:** 加入 stem:[E], `result` = stem:[{A, B, C, D, E}].

最终 stem:[(AC)^+ = {A, B, C, D, E}], 包含了全部属性.

* 如果检查 stem:[ A^+ ] 或 stem:[ C^+ ], 它们都无法包含全部属性.

* 所以, stem:[(A, C)] 就是该关系模式的一个候选键.

=== 关键注意事项

* **闭包的传递性:** 闭包利用了函数依赖的传递性(结合 Armstrong 公理中的传递律), 因此结果往往是"一步推一步"累积出来的.

* **与函数依赖集闭包的区别:**

** **属性集闭包 stem:[X^+]:** 指从 stem:[X] 能推出多少个属性.

** **函数依赖集闭包 stem:[ F^+ ]:** 指从 stem:[F] 能推出多少条函数依赖. 属性集闭包通常是计算 stem:[F^+] 的基础.
