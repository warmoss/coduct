== 排列组合原理讲解

排列组合是组合数学的基础, 主要研究从一组对象中选取若干对象并考虑顺序或不考虑顺序的方法总数. 掌握排列组合, 首先要理解两个最基本的计数原理: 加法原理和乘法原理.

=== 两个基本计数原理

==== 分类加法计数原理 (加法原理)

做一件事, 完成它有 stem:[n] 类不同方案. 第 1 类有 stem:[m_1] 种方法, 第 2 类有 stem:[m_2] 种方法, ..., 第 stem:[n] 类有 stem:[m_n] 种方法, 那么完成这件事共有

stem:[N = m_1 + m_2 + \dots + m_n]

种不同的方法.

关键: "分类" —— 每一类都能独立完成这件事, 类与类之间用加法.

例子: 从上海到北京, 可以坐飞机 (有 3 个航班) 或坐高铁 (有 4 个车次), 那么从上海到北京共有 stem:[3+4=7] 种方式.

==== 分步乘法计数原理 (乘法原理)

做一件事, 需要分成 stem:[n] 个步骤. 第 1 步有 stem:[m_1] 种方法, 第 2 步有 stem:[m_2] 种方法, ..., 第 stem:[n] 步有 stem:[m_n] 种方法, 那么完成这件事共有

stem:[N = m_1 \times m_2 \times \dots \times m_n]

种不同的方法.

关键: "分步" —— 每一步只是完成这件事的一部分, 必须依次做完所有步骤才能完成, 步与步之间用乘法.

例子: 从上海到北京, 先坐飞机到南京 (有 2 个航班), 再坐高铁从南京到北京 (有 3 个车次), 那么从上海到北京共有 stem:[2 \times 3 = 6] 种方式.

注意: 很多时候需要同时使用加法原理和乘法原理 (先分类, 每类里再分步等), 关键是区分"类"与"步".

=== 排列

==== 定义

从 stem:[n] 个不同元素中, 取出 stem:[m] (stem:[m \le n]) 个元素, 按照一定的顺序排成一列, 叫做从 stem:[n] 个不同元素中取出 stem:[m] 个元素的一个排列. 所有不同排列的个数, 记作 stem:[A_n^m] 或 stem:[P_n^m].

==== 计算公式

stem:[A_n^m = n \times (n-1) \times (n-2) \times \dots \times (n-m+1) = \frac{n!}{(n-m)!}]

特别地, 当 stem:[m=n] 时, stem:[A_n^n = n!] (称为全排列).

==== 理解

排列关心顺序. 例如, 从 {A, B, C} 中选 2 个元素排列, AB 和 BA 被视为两种不同的结果.

例子: 从 3 个不同的数字 1,2,3 中选出 2 个组成两位数.

第一步选十位: 3 种选法; 第二步选个位: 剩下 2 种选法.

总数为 stem:[3 \times 2 = 6], 即 stem:[A_3^2 = 6].

具体排列: 12,13,21,23,31,32.

=== 组合

==== 定义

从 stem:[n] 个不同元素中, 取出 stem:[m] (stem:[m \le n]) 个元素, 不考虑顺序, 叫做从 stem:[n] 个不同元素中取出 stem:[m] 个元素的一个组合. 所有不同组合的个数, 记作 stem:[C_n^m].

==== 计算公式

stem:[C_n^m = \frac{A_n^m}{A_m^m} = \frac{n!}{m! (n-m)!}]

常用性质:

stem:[C_n^m = C_n^{n-m}]

stem:[C_n^0 = C_n^n = 1]

stem:[C_n^m = C_{n-1}^{m-1} + C_{n-1}^m] (杨辉三角递推式)

==== 理解

组合不关心顺序. 例如, 从 {A, B, C} 中选 2 个元素, 组合有: AB, AC, BC, 共 3 种. 而排列有 6 种, 因为 AB 和 BA 在组合中视为同一个.

例子: 从 4 个人中选 2 人组成一个小组, 有多少种选法?

stem:[C_4^2 = \frac{4 \times 3}{2 \times 1} = 6]

如果小组分正副组长 (有顺序), 则是排列 stem:[A_4^2 = 12] 种.

=== 排列与组合的对比

[cols="2,3,3"]
|===
|项目|排列|组合

|是否考虑顺序|是|否
|符号|stem:[A_n^m]|stem:[C_n^m]
|公式|stem:[\frac{n!}{(n-m)!}]|stem:[\frac{n!}{m!(n-m)!}]
|关系|stem:[A_n^m = C_n^m \times A_m^m = C_n^m \times m!]|stem:[C_n^m = A_n^m / (m!)]
|===

**一句话:** 先组合 (选元素), 再排列 (对选出的元素排序).

=== 常见题型及解题思路

==== 无限制的排列/组合问题

直接使用公式计算.

==== 有限制条件的问题

* **特殊元素优先处理:** 先安排有特殊要求的人或物.

* **相邻问题(捆绑法):** 要求某些元素相邻, 把它们看作一个整体, 再与其余元素排列, 注意内部可排列.

* **不相邻问题(插空法):** 先排其他元素, 再在产生的空位中插入要求不相邻的元素.

* **定序问题(除以阶乘):** 若某些元素顺序固定, 则先全排列, 再除以这些元素的阶乘.

* **分组分配问题:** 平均分组 (注意去重), 非平均分组, 部分平均分组等, 常结合乘法原理.

==== 注意元素是否相同

以上排列组合公式针对不同元素. 若元素有相同 (如字母重复), 则需用多重组排列公式, 即 stem:[(n!) / (n_1! * n_2! * \dots * n_k!)].

=== 典型例题

**例1:** 用 0~9 十个数字组成没有重复数字的三位数, 有多少个?

* 百位不能为 0: 先选百位, 有 stem:[A_9^1 = 9] 种 (从 1~9 选 1 个);

* 再选十位和个位: 从剩下 9 个数字选 2 个排列, 有 stem:[A_9^2 = 72] 种;

* 总数: stem:[9 \times 72 = 648] (也可用 stem:[A_{10}^3 - A_9^2 = 720 - 72 = 648]).

**例2:** 有 5 本不同的书, 分给 3 个人, 每人至少一本, 有多少种分法?

* 先分组: 5 本书分成 3 组, 有两种分组方式: 3,1,1 和 2,2,1.

** 3,1,1: 选出 3 本给一人, 剩下各 1 本. 但有两个 1 本组相同, 故分组数为 stem:[\frac{C_5^3 C_2^1 C_1^1}{2!} = 10].

** 2,2,1: 选出 1 本给一人, 剩下 4 本平均分成两堆, 分组数为 stem:[\frac{C_5^1 C_4^2 C_2^2}{2!} = 15].

* 再分配: 将三组书分配给 3 个人, 有 stem:[3! = 6] 种分配方式.

* 总数: stem:[(10+15) \times 6 = 150] 种.

=== 总结

排列组合的核心思想是:

. 判断问题是"分类"还是"分步".

. 区分"排列"与"组合"——顺序是否重要.

. 遇到限制条件, 灵活使用"优先安排", "捆绑", "插空", "去重"等方法.

. 熟练运用公式并注意公式的适用范围 (元素不同, 无放回).

通过大量练习, 逐渐培养对"顺序感"的敏锐度, 排列组合就会变得清晰而有趣.
