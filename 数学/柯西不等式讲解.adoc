== 柯西不等式讲解

柯西不等式(Cauchy-Schwarz Inequality)是数学中最基础、应用最广泛的不等式之一, 由法国数学家**柯西(Cauchy)**于1821年提出, 后由德国数学家**施瓦茨(Schwarz)**推广到积分形式. 它揭示了"两个向量的内积不超过它们模长的乘积"这一核心事实, 在代数、几何、分析、概率论中均有深远应用.

=== 代数形式

对于任意实数序列 stem:[a_1, a_2, \dots, a_n] 和 stem:[b_1, b_2, \dots, b_n], 有:

stem:[(a_1^2 + a_2^2 + \dots + a_n^2)(b_1^2 + b_2^2 + \dots + b_n^2) \geq (a_1 b_1 + a_2 b_2 + \dots + a_n b_n)^2]

简记为:

stem:[\left( \sum_{i=1}^n a_i^2 \right) \left( \sum_{i=1}^n b_i^2 \right) \geq \left( \sum_{i=1}^n a_i b_i \right)^2]

二维情形下, 它退化为:

stem:[(a_1^2 + a_2^2)(b_1^2 + b_2^2) \geq (a_1 b_1 + a_2 b_2)^2]

这就是中学数学中最常见的形式.

=== 向量形式

若将 stem:[a_i] 和 stem:[b_i] 视为 stem:[n] 维向量 stem:[\mathbf{a} = (a_1, \dots, a_n)] 和 stem:[\mathbf{b} = (b_1, \dots, b_n)], 柯西不等式可写成:

stem:[|\mathbf{a} \cdot \mathbf{b}| \leq \|\mathbf{a}\| \, \|\mathbf{b}\|]

其中 stem:[\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^n a_i b_i] 是向量的点积, stem:[\|\mathbf{a}\| = \sqrt{\sum a_i^2}] 是向量的模长.

由此可定义两向量夹角的余弦:

stem:[\cos \theta = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|} \in [-1, 1]]

柯西不等式正是保证了这个比值落在 stem:[ [-1, 1] ] 区间内, 从而确保夹角定义是良性的. 关于向量点积的更多内容, 参见 `<<向量原理讲解.adoc#, 向量原理讲解>>`.

=== 证明

柯西不等式有多种证明方法, 以下介绍两种最经典的证法.

==== 判别式法(构造二次函数)

构造关于 stem:[t] 的二次函数:

stem:[f(t) = \sum_{i=1}^n (a_i t + b_i)^2 = \left( \sum a_i^2 \right) t^2 + 2 \left( \sum a_i b_i \right) t + \left( \sum b_i^2 \right)]

由于 stem:[f(t)] 是若干个平方项之和, 对任意实数 stem:[t] 恒有 stem:[f(t) \geq 0]. 这意味着其判别式 stem:[\Delta \leq 0]:

stem:[\Delta = 4 \left( \sum a_i b_i \right)^2 - 4 \left( \sum a_i^2 \right) \left( \sum b_i^2 \right) \leq 0]

整理即得:

stem:[\left( \sum a_i^2 \right) \left( \sum b_i^2 \right) \geq \left( \sum a_i b_i \right)^2]

.WARNING: 当 stem:[\Delta = 0] 时不等式取等号, 即 stem:[f(t)] 有重根, 这意味着所有 stem:[a_i] 与 stem:[b_i] 对应成比例.

==== 向量内积法

由向量内积的几何定义:

stem:[\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos \theta]

直接取绝对值即得:

stem:[|\mathbf{a} \cdot \mathbf{b}| = \|\mathbf{a}\| \|\mathbf{b}\| |\cos \theta| \leq \|\mathbf{a}\| \|\mathbf{b}\|]

这是最简洁的证法, 但其前提是已从代数层面建立了向量内积与 stem:[\cos \theta] 的关系.

=== 取等条件

柯西不等式取等号当且仅当两组数对应成比例, 即存在常数 stem:[k] 使得:

stem:[a_i = k \, b_i \quad (i = 1, 2, \dots, n)]

(当某些 stem:[b_i = 0] 时, 对应的 stem:[a_i] 也必须为0)

以向量语言表述, 即 stem:[\mathbf{a}] 与 stem:[\mathbf{b}] **共线**(线性相关).

=== 常见变形

以下变形在解题中频繁出现:

[cols="1,2"]
|===
| 变形形式 | 适用场景

| stem:[\sum a_i^2 \geq \frac{(\sum a_i)^2}{n}]
| 求平方和的最小值(令 stem:[b_i = 1] 即得)

| stem:[\sum \frac{a_i^2}{b_i} \geq \frac{(\sum a_i)^2}{\sum b_i}]
| 分式求和的最值问题(stem:[b_i > 0])

| stem:[\sum a_i b_i \leq \sqrt{\sum a_i^2} \sqrt{\sum b_i^2}]
| 估计内积上界

|===

=== 应用示例

==== 求函数最值

已知 stem:[x, y > 0] 且 stem:[x + y = 1], 求 stem:[\frac{1}{x} + \frac{4}{y}] 的最小值.

由柯西不等式的分式变形:

stem:[\frac{1}{x} + \frac{4}{y} = \frac{1^2}{x} + \frac{2^2}{y} \geq \frac{(1 + 2)^2}{x + y} = \frac{9}{1} = 9]

当 stem:[\frac{1}{x} : \frac{2}{y} = x : y], 即 stem:[x = \frac{1}{3}, y = \frac{2}{3}] 时取等.

==== 证明其他不等式

柯西不等式常用于证明其他重要不等式. 例如利用柯西不等式可快速证出**三角不等式**:

stem:[\|\mathbf{a} + \mathbf{b}\|^2 = \|\mathbf{a}\|^2 + 2 \mathbf{a} \cdot \mathbf{b} + \|\mathbf{b}\|^2 \leq \|\mathbf{a}\|^2 + 2 \|\mathbf{a}\| \|\mathbf{b}\| + \|\mathbf{b}\|^2 = (\|\mathbf{a}\| + \|\mathbf{b}\|)^2]

两边开平方即得 stem:[\|\mathbf{a} + \mathbf{b}\| \leq \|\mathbf{a}\| + \|\mathbf{b}\|].

==== 概率论中的应用

设随机变量 stem:[X] 和 stem:[Y], 柯西不等式表现为:

stem:[(E[XY\])^2 \leq E[X^2\] \, E[Y^2\]]

取 stem:[X] 和 stem:[Y] 为中心化后的随机变量, 上式等价于相关系数 stem:[\rho \in [-1, 1]].

=== 推广

==== 赫尔德不等式(Hölder)

柯西不等式是赫尔德不等式在 stem:[p = q = 2] 时的特例:

stem:[\sum_{i=1}^n |a_i b_i| \leq \left( \sum_{i=1}^n |a_i|^p \right)^{1/p} \left( \sum_{i=1}^n |b_i|^q \right)^{1/q}, \quad \frac{1}{p} + \frac{1}{q} = 1]

当 stem:[p = q = 2] 时, 赫尔德不等式退化为柯西不等式.

==== 积分形式(施瓦茨不等式)

将求和推广到积分, 得到柯西-施瓦茨积分不等式:

stem:[\left( \int_a^b f(x) g(x) \, dx \right)^2 \leq \int_a^b f^2(x) \, dx \int_a^b g^2(x) \, dx]

这在内积空间理论中占据核心地位, 是泛函分析中证明许多定理的出发点.

=== 总结

* 柯西不等式的核心是 stem:[(\sum a_i^2)(\sum b_i^2) \geq (\sum a_i b_i)^2], 即"平方和的乘积 >= 乘积和的平方".
* 它在向量语言中等价于 stem:[|\mathbf{a} \cdot \mathbf{b}| \leq \|\mathbf{a}\| \|\mathbf{b}\|], 即内积不超过模长的乘积.
* 取等条件是两组数(向量)成比例(共线).
* 证明思路多样, 判别式法最通用, 向量法最直观.
* 它是许多更高级不等式(赫尔德不等式, 闵可夫斯基不等式)的基石.

IMPORTANT: 柯西不等式只适用于实数. 对复数需要将 stem:[b_i^2] 替换为 stem:[|b_i|^2], stem:[a_i b_i] 替换为 stem:[|a_i b_i|] 或取共轭 stem:[a_i \overline{b_i}].
