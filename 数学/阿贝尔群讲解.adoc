== 阿贝尔群讲解

**阿贝尔群(Abelian Group)**, 又称**交换群(Commutative Group)**, 是一类满足**交换律**的特殊群. 它以挪威数学家尼尔斯·亨利克·阿贝尔(Niels Henrik Abel)命名, 是群论中最基本且最重要的结构之一. 在计算机科学中, 阿贝尔群是许多密码学算法, 并行计算模型和分布式系统一致性协议背后的数学基石.

=== 前置概念

在理解阿贝尔群之前, 需要先掌握群的基本概念:

群(Group)::
一个集合 stem:[G] 配合一个二元运算 stem:[*], 满足以下四个条件:
+
* **封闭性:** 对任意 stem:[a, b in G], stem:[a * b in G]
* **结合律:** 对任意 stem:[a, b, c in G], stem:[(a * b) * c = a * (b * c)]
* **单位元:** 存在 stem:[e in G], 使得对任意 stem:[a in G], stem:[e * a = a * e = a]
* **逆元:** 对任意 stem:[a in G], 存在 stem:[a^{-1} in G], 使得 stem:[a * a^{-1} = a^{-1} * a = e]
+
关于群的详细讨论, 可参考 `<<数学/拉格朗日定理讲解.adoc, 拉格朗日定理讲解>>` 中的前置概念部分.

=== 定义

阿贝尔群是在普通群的基础上**增加交换律**得到的:

[stem]
++++
\forall a, b \in G, \quad a * b = b * a
++++

用文字表述: 对于群中任意两个元素, 运算的**先后顺序不影响结果**.

[IMPORTANT]
====
阿贝尔群 = 群 + 交换律. 并非所有群都是阿贝尔群, 交换律是一个很强的约束条件.
====

=== 典型例子

==== 整数加法群 stem:[(ZZ, +)]

整数在加法下构成阿贝尔群:

* 封闭性: 两个整数之和仍是整数
* 结合律: stem:[(a + b) + c = a + (b + c)]
* 单位元: stem:[0]
* 逆元: stem:[a] 的逆元是 stem:[-a]
* **交换律: stem:[a + b = b + a]**

这是最直观的阿贝尔群示例. 实际上, 加法群通常用 stem:[+] 表示运算, 单位元用 stem:[0] 表示.

[source,java]
----
// 整数加法群的模拟
int a = 5, b = 3;
assert a + b == b + a;  // 交换律成立
----

==== 模 n 加法群 stem:[(ZZ/nZZ, +)]

模 stem:[n] 的剩余类在加法下也构成阿贝尔群:

* 集合: stem:[\{0, 1, 2, ..., n-1\}]
* 运算: 模 stem:[n] 加法
* 单位元: stem:[0]
* 逆元: stem:[a] 的逆元是 stem:[n - a \pmod{n}]

**例子:** 在 stem:[ZZ/6ZZ] 中, stem:[2 + 5 = 7 equiv 1 pmod{6}], 而 stem:[5 + 2 = 7 equiv 1 pmod{6}], 交换律成立.

==== 非零实数乘法群 stem:[(RR^*, xx)]

非零实数在乘法下构成阿贝尔群:

* 封闭性: 两个非零实数之积仍为非零实数
* 结合律: stem:[(a * b) * c = a * (b * c)]
* 单位元: stem:[1]
* 逆元: stem:[a] 的逆元是 stem:[1/a]
* **交换律: stem:[a * b = b * a]**

==== 向量加法群

stem:[n] 维实向量在向量加法下构成阿贝尔群:

[stem]
++++
\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}, \quad \mathbf{u}, \mathbf{v} \in \mathbb{R}^n
++++

向量加法群是线性代数的基石 — 事实上, 向量空间定义中的"加法群"必须是阿贝尔群.

=== 非阿贝尔群的例子

并非所有群都满足交换律. 以下是一些典型的**非阿贝尔群**:

* **对称群 stem:[S_3]:** 3 个元素的置换群. 例如, 先交换 1 和 2, 再交换 2 和 3, 与先交换 2 和 3, 再交换 1 和 2, 结果不同.
* **一般线性群 stem:[GL(n, RR)]:** stem:[n xx n] 可逆矩阵在乘法下构成的群. 矩阵乘法不满足交换律: stem:[AB != BA].
* **二面体群 stem:[D_n]:** 正 stem:[n] 边形的对称群. 旋转和反射的复合顺序不可交换.

[source,python]
----
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 1], [1, 0]])

# 矩阵乘法不交换
print(np.array_equal(A @ B, B @ A))  # False
----

=== 核心性质

==== 子群必为阿贝尔群

阿贝尔群的任意**子群**也是阿贝尔群. 这是显然的: 如果交换律对整个群成立, 那么对任何子集自然也成立.

==== 所有子群都是正规子群

在阿贝尔群中, **每个子群都是正规子群**. 这是因为正规子群的定义条件 stem:[gHg^{-1} = H] 在交换群中自动满足: stem:[g * h * g^{-1} = g * g^{-1} * h = h in H].

这一性质意味着在阿贝尔群上构造**商群**非常自然, 不需要额外验证正规性条件.

==== 有限生成阿贝尔群基本定理

这是阿贝尔群理论中最深刻的结构定理:

[IMPORTANT]
====
任何**有限生成的阿贝尔群**都同构于若干**循环群**的直和. 具体地说, 一个有限生成阿贝尔群 stem:[G] 同构于:

[stem]
++++
\mathbb{Z}^r \oplus \mathbb{Z}/n_1\mathbb{Z} \oplus \mathbb{Z}/n_2\mathbb{Z} \oplus \cdots \oplus \mathbb{Z}/n_k\mathbb{Z}
++++

其中 stem:[r] 是**秩(rank)**, stem:[n_i] 满足 stem:[n_1 \mid n_2 \mid ... \mid n_k].
====

这个定理告诉我们: 阿贝尔群的结构完全由循环群刻画, 没有神秘之处. 正是这种"可完全分类"的性质, 使阿贝尔群在理论和应用中都极为重要.

==== 与拉格朗日定理的关系

阿贝尔群同样适用拉格朗日定理: 子群的阶整除群的阶. 但在阿贝尔群中, 拉格朗日定理的**逆命题不一定成立** — 即, 并非每个整除群阶的数都对应一个该阶的子群. 不过, 对于有限阿贝尔群, 这一逆命题在特定条件下可以成立(例如西罗定理在阿贝尔群中的简化形式).

=== 阿贝尔群在密码学中的应用

==== 椭圆曲线密码学(ECC)

椭圆曲线上的点配合"点加"运算构成一个**阿贝尔群**. 这是 ECC 安全性的数学基础:

* 给定两点 stem:[P] 和 stem:[Q], 计算 stem:[P + Q] 是容易的
* 给定 stem:[P] 和 stem:[kP], 求 stem:[k] 是困难的(椭圆曲线离散对数问题)
* 点加运算**满足交换律**: stem:[P + Q = Q + P]

[source,python]
----
# 椭圆曲线上点加的交换律示意(伪代码)
# P + Q == Q + P  始终成立
# 这是 ECDH 密钥交换能正常工作的前提
----

==== Diffie-Hellman 密钥交换

DH 密钥交换协议的安全性依赖于任意阿贝尔群上的离散对数问题:

. Alice 选择私钥 stem:[a], 计算公钥 stem:[g^a] 发送给 Bob
. Bob 选择私钥 stem:[b], 计算公钥 stem:[g^b] 发送给 Alice
. 双方各自计算共享密钥: Alice 计算 stem:[(g^b)^a = g^{ab}], Bob 计算 stem:[(g^a)^b = g^{ab}]

关键在于 stem:[g^{ab} = g^{ba}], 这正是阿贝尔群交换律的体现. 没有交换律, 双方无法得到相同的共享密钥.

==== Pedersen 承诺

在区块链和零知识证明中广泛使用的 Pedersen 承诺方案, 也依赖于阿贝尔群的性质:

[stem]
++++
C = g^v \cdot h^r
++++

其中 stem:[v] 是要承诺的值(秘密), stem:[r] 是随机盲化因子. 承诺的**隐藏性**和**绑定性**都依赖于底层阿贝尔群中离散对数问题的难解性.

=== 阿贝尔群在计算机科学中的其他应用

==== 并行计算与可交换归约

阿贝尔群的交换律意味着归约操作的**顺序无关紧要**. 这使得并行归约(parallel reduction)成为可能:

[source,java]
----
// 数组求和: 加法是交换的, 可以任意顺序并行累加
int[] arr = {1, 2, 3, 4, 5, 6, 7, 8};

// 并行归约示意:
// 线程1: 1 + 2 = 3,  3 + 3 = 6,  6 + 4 = 10
// 线程2: 5 + 6 = 11, 11 + 7 = 18, 18 + 8 = 26
// 合并:  10 + 26 = 36  (顺序无关)
----

MapReduce 中的 Reduce 阶段, GPU 中的 parallel reduction 算法, 都建立在运算满足交换律(和结合律)的基础之上.

==== 分布式系统中的 CRDT

**无冲突复制数据类型(CRDT)** 是实现最终一致性的关键技术. 其中一类重要的 CRDT — **基于状态的 CRDT (State-based CRDT, 即 CvRDT)** — 其合并(merge)操作必须满足交换律, 结合律和幂等律, 即构成一个**半格(join-semilattice)**. 虽然半格不是群, 但交换律带来的一致性保证与阿贝尔群中的推理高度相似:

* 无论副本以何种顺序接收更新, 最终结果一致
* 合并操作可以乱序, 重复执行, 不会破坏一致性

这种"顺序无关"特性正是阿贝尔群思想在分布式系统中的延伸.

| 加法群用 stem:[+] 表示运算, 单位元为 stem:[0]; 乘法群用 stem:[*] 或 stem:[cdot], 单位元为 stem:[1]

| **密码学应用**
| ECC 椭圆曲线密码学, DH 密钥交换, Pedersen 承诺 — 安全性均基于阿贝尔群上的离散对数问题

| **系统应用**
