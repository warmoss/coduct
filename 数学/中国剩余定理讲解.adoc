== 中国剩余定理讲解

**中国剩余定理**是一个关于**一元线性同余方程组**的定理, 它在数论、密码学、计算机科学等领域有广泛的应用.

=== 历史背景与引言
中国剩余定理, 又称" 孙子定理" , 最早出现在中国古代数学著作《孙子算经》(约公元3-5世纪)中. 原题是:

[quote]
今有物不知其数, 三三数之剩二, 五五数之剩三, 七七数之剩二. 问物几何?

用现代数学语言描述就是: 有一个数, 除以3余2, 除以5余3, 除以7余2, 求这个数是多少.

中国剩余定理完美地、系统化地解决了一类这样的问题.

=== 定理描述(现代数学语言)

定理前提(互质情形)::
设 stem:[m_1, m_2, ..., m_k]是 k 个**两两互质**且大于1的整数. 也就是说, 对于任何 stem:[i != j], 有 stem:[gcd(m_i, m_j) = 1].

同余方程组::
考虑如下方程组:
[stem]
++++
{
    (x -= a_1 (mod m_1)),
    (x -= a_2 (mod m_2)),
    (vdots),
    (x -= a_k (mod m_k))
:}
++++

中国剩余定理的结论::

解的存在性与唯一性:::
这个方程组在模 stem:[M = m_1 xx m_2 xx ldots xx m_k]的意义下有 **唯一解**.
* 即, 解 stem:[x] 是唯一存在的, 并且所有解相差 stem:[M] 的整数倍(即通解为 stem:[x + kM, k in Z]).

解的构造(求解步骤):::

* **步骤 1:** 计算所有模数的乘积 stem:[M = m_1 xx m_2 xx ldots xx m_k].

* **步骤 2:** 对每个模数 stem:[m_i], 计算 stem:[M_i = M // m_i].

** stem:[M_i] 是所有其他模数的乘积, 因为模数两两互质, 所以 stem:[gcd(m_i, M_i) = 1].

* **步骤 3:** 对每个 stem:[M_i], 求它在模 stem:[m_i] 下的 **数论倒数** stem:[t_i].

** 即, 寻找 stem:[t_i] 使得 stem:[M_i xx t_i -= 1 (mod m_i)].

** 因为 stem:[M_i] 和 stem:[m_i] 互质, 这个倒数 stem:[t_i] 一定存在(可以使用扩展欧几里得算法求出).

* **步骤 4:** 方程组的唯一解(在模 stem:[M] 的意义下)为:

[stem]
++++
x = (a_1 t_1 M_1 + a_2 t_2 M_2 + ldots + a_k t_k M_k) mod M
++++

=== 实例演示: 解决《孙子算经》中的问题
让我们用现代方法来解决那个经典问题:

[stem]
++++
{
    (x -= 2 (mod 3)),
    (x -= 3 (mod 5)),
    (vdots),
    (x -= 2 (mod 7))
:}
++++
 
**按照步骤求解:**

. 计算 stem:[M]:
+
stem:[m_1 = 3], stem:[m_2 = 5], stem:[m_3 = 7], 它们两两互质.
+
stem:[M = 3 xx 5 xx 7 = 105]

. 计算每个 stem:[M_i]:
+
stem:[M_1 = M // m_1 = 105 // 3 = 35]
+
stem:[M_2 = M // m_2 = 105 // 5 = 21]
+
stem:[M_3 = M // m_3 = 105 // 7 = 15]

. 求每个 stem:[M_i] 在模 stem:[m_i] 下的倒数 stem:[t_i]:

** 求 stem:[t_1]: stem:[35 xx t_1 -= 1 (mod 3)]
+
stem:[35 -: 3] 余 stem:[2] (stem:[35 = 11 xx 3 + 2]), 所以方程简化为 stem:[2 xx t_1 -= 1 (mod 3)].
+
尝试 stem:[t_1 = 2], 因为 stem:[2 xx 2 = 4 -= 1 (mod 3)]. 所以 stem:[t_1 = 2].

** 求 stem:[t_2]: stem:[21 xx t_2 -= 1 (mod 5)]
+
stem:[21 -: 5] 余 stem:[1], 所以方程简化为 stem:[1 xx t_2 -= 1 (mod 5)]. 所以 stem:[t_2 = 1].

** 求 stem:[t_3]: stem:[15 xx t_3 -= 1 (mod 7)]
+
stem:[15 -: 7] 余 stem:[1] (stem:[15 = 2 xx 7 + 1]), 所以方程简化为 stem:[1 xx t_3 -= 1 (mod 7)]. 所以 stem:[t_3 = 1].

. 构造解 stem:[x]:

[stem]
++++
x = (a_1 t_1 M_1 + a_2 t_2 M_2 + a_3 t_3 M_3) mod M \
  = (2 xx 2 xx 35 + 3 xx 1 xx 21 + 2 xx 1 xx 15) mod 105 \
  = (140 + 63 + 30) mod 105 \
  = 233 mod 105 \
  = 23
++++

**结论:** 最小的正整数解是 **23**. 所有解的形式是 stem:[23 + 105k] (k为任意整数), 例如 23, 128, 233, -82 等等.

你可以验证一下:

stem:[23 -: 3 = 7] 余 stem:[2] icon:check[role=green]

stem:[23 -: 5 = 4] 余 stem:[3] icon:check[role=green]

stem:[23 -: 7 = 3] 余 stem:[2] icon:check[role=green]

完美!

=== 定理的价值与意义
* **大数计算:** 可以将大整数的运算分解为几个较小模数下的运算, 最后再通过中国剩余定理合并结果. 这在计算机硬件和密码学中非常有用.

* **密码学基础:** RSA公钥密码体系等高级加密算法的计算和证明中, 大量使用了中国剩余定理.

* **数论核心:** 它是模算术理论中的一个基石, 揭示了模数分解后解的结构关系.

=== 重要说明: 模数不互质的情况
中国剩余定理有一个重要前提: **模数必须两两互质**.

如果模数不互质, 会发生两种情况:

. **方程组无解**.

** 例如: stem:[x -= 1 (mod 4)] 和 stem:[x -= 2 (mod 6)] 无解. 因为第一个方程要求stem:[x]是奇数, 第二个方程要求stem:[x]是偶数, 矛盾.

. **方程组有解, 但在模所有数的最小公倍数(LCM)的意义下有唯一解**.

** 例如: stem:[x -= 2 (mod 4)] 和 stem:[x -= 4 (mod 6)]. 解是 stem:[x -= 10 (mod 12)] (stem:[LCM(4, 6) = 12]). 这种情况下, 可以通过扩展的中国剩余定理求解.

对于模不互质的情况, 求解过程会更复杂, 需要逐个合并方程.
