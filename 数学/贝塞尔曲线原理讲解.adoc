== 贝塞尔曲线原理讲解

贝塞尔曲线(Bézier Curve)是一种由**控制点**定义的**参数曲线**, 广泛应用于计算机图形学、矢量图形、字体设计、动画缓动函数和路径规划等领域. 它以法国工程师 Pierre Bézier 命名, 最初用于雷诺公司的汽车车身设计.

=== 什么是贝塞尔曲线

贝塞尔曲线的核心思想是: 给定一组**控制点**, 通过一个数学公式产生一条光滑曲线, 曲线本身不一定要穿过所有控制点(仅首尾端点穿过), 而是被控制点"**牵引**"出形状.

定义列表::

贝塞尔曲线:: 由 **n+1** 个控制点定义的 **n** 次参数曲线, 通过 **伯恩斯坦多项式(Bernstein Polynomial)** 作为基函数混合各控制点坐标生成.
控制点:: 定义曲线形状的锚点, 记作 stem:[P_0, P_1, ..., P_n]. 其中 stem:[P_0] 和 stem:[P_n] 是曲线的**起点**和**终点**.
参数 t:: 取值范围 stem:[0 \le t \le 1], 表示沿曲线的位置比例. stem:[t=0] 对应起点, stem:[t=1] 对应终点.

=== 数学定义

贝塞尔曲线的通用公式为:

stem:[B(t) = \sum_{i=0}^{n} \binom{n}{i} (1-t)^{n-i} t^i P_i, \quad t \in [0,1]]

其中 stem:[\binom{n}{i}] 是二项式系数, stem:[(1-t)^{n-i} t^i] 是 **n** 次伯恩斯坦基函数.

==== 一阶贝塞尔曲线(线性)

两个控制点 stem:[P_0, P_1] 定义一条直线段. 公式简化为:

stem:[B(t) = (1-t) P_0 + t P_1]

这本质上就是两点间的线性插值(lerp).

==== 二阶贝塞尔曲线(二次)

三个控制点 stem:[P_0, P_1, P_2] 定义一条抛物线弧段:

stem:[B(t) = (1-t)^2 P_0 + 2(1-t)t P_1 + t^2 P_2]

几何构造过程(De Casteljau 算法):

. 在线段 stem:[P_0P_1] 上按比例 stem:[t] 取点 stem:[Q_0]
. 在线段 stem:[P_1P_2] 上按比例 stem:[t] 取点 stem:[Q_1]
. 在线段 stem:[Q_0Q_1] 上按比例 stem:[t] 取点 stem:[B(t)], 该点即为曲线上的一点

==== 三阶贝塞尔曲线(三次)

四个控制点 stem:[P_0, P_1, P_2, P_3] 定义一条三次曲线, 也是实际应用最广泛的形式:

stem:[B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3]

三阶贝塞尔曲线是计算机图形学的核心, 因为它:

* 保证曲线平滑且连续
* 计算复杂度可控
* 提供足够的自由度控制形状

=== 核心特性

贝塞尔曲线具有以下重要性质:

* **端点插值**: 曲线总是穿过起点 stem:[P_0] 和终点 stem:[P_n], 但不一定穿过中间控制点.
* **凸包性**: 整条曲线完全包含在控制点形成的**凸包**(Convex Hull)内. 这一性质使得曲线行为可预测, 对碰撞检测等应用至关重要.
* **仿射不变性**: 对曲线应用任何**仿射变换**(平移、旋转、缩放), 等价于先对控制点做相同变换再生成曲线. 这极大简化了图形变换操作.
* **变差缩减性(Variation Diminishing)**: 曲线不会比连接控制点的折线产生更多"摆动", 即曲线比控制多边形更平滑.
* **全局控制性**: 移动任意一个控制点都会影响**整条**曲线的形状(与 B 样条曲线不同).

=== De Casteljau 算法

De Casteljau 算法是计算贝塞尔曲线上任意点的**递推方法**, 通过反复的线性插值逐步收敛到目标点.

----
给定控制点 P₀, P₁, ..., Pₙ 和参数 t
                    P₀
                   / \
                 P₀¹  P₁¹       第一次插值: Pᵢ¹ = (1-t)Pᵢ + tPᵢ₊₁
                 / \ / \
               P₀²  P₁²  P₂²    第二次插值
               ...逐渐收敛
                 / \
               P₀ⁿ⁻¹  P₁ⁿ⁻¹
                   \ /
                    P₀ⁿ         最终结果 = B(t)
----

递推公式:

stem:[P_i^0 = P_i]

stem:[P_i^r = (1-t) P_i^{r-1} + t P_{i+1}^{r-1}, \quad r = 1, 2, ..., n; \; i = 0, 1, ..., n-r]

最终 stem:[P_0^n] 即为 stem:[B(t)].

De Casteljau 算法的另一个优势是: 计算曲线上一点的同时, 也把曲线递归切分成了两个子曲线段, 便于细分渲染.

=== 应用场景

==== 计算机图形学 & 字体设计

TrueType 和 PostScript 字体使用贝塞尔曲线来描述字形轮廓. TrueType 使用**二阶贝塞尔曲线**, PostScript 使用**三阶贝塞尔曲线**.

==== CSS 动画缓动函数

CSS 的 `cubic-bezier()` 函数使用三阶贝塞尔曲线定义动画速度曲线. 起点固定为 stem:[(0,0)], 终点固定为 stem:[(1,1)], 中间两个控制点可自由调节.

[source,css]
----
/* CSS 动画缓动函数: cubic-bezier(x1, y1, x2, y2) */
/* 控制点 P₁(0.25, 0.1) 和 P₂(0.25, 1.0) 定义了一个 ease 曲线 */
.element {
    transition: transform 0.3s cubic-bezier(0.25, 0.1, 0.25, 1.0);
}
----

常见预定义缓动函数:

[cols="3*"]
|===
| 名称 | cubic-bezier 值 | 效果描述

| `ease` | `(0.25, 0.1, 0.25, 1.0)` | 慢→快→慢(默认)
| `ease-in` | `(0.42, 0, 1.0, 1.0)` | 慢→快(加速)
| `ease-out` | `(0, 0, 0.58, 1.0)` | 快→慢(减速)
| `ease-in-out` | `(0.42, 0, 0.58, 1.0)` | 慢→快→慢(对称)
| `linear` | `(0, 0, 1, 1)` | 匀速
|===

WARNING: CSS `cubic-bezier()` 的横轴始终为时间(stem:[0,1]), 纵轴为进度(stem:[0,1]). 超出 stem:[0,1] 范围的值会产生回弹效果.

==== 矢量图形 & 路径绘制

SVG 路径中的 `C` 命令使用三阶贝塞尔曲线, `Q` 命令使用二阶贝塞尔曲线.

----

=== 贝塞尔曲线 vs B 样条曲线

|===
| 特性 | 贝塞尔曲线 | B 样条曲线

| 控制点数量 | 阶次 + 1 | 独立于阶次
| 局部控制 | 否(移动任一点影响全局) | 是(移动一点仅影响局部)
| 凸包性 | 整体凸包 | 分段凸包(更紧致)
| 连续性 | 拼接处需额外约束 | 内置连续
| 适用场景 | 简单形状、字体、UI 动画 | 复杂工业曲面、CAD
|===

=== 总结

* 贝塞尔曲线由控制点通过**伯恩斯坦多项式**混合生成, 曲线仅穿过首尾控制点.
* **De Casteljau 算法**是递归计算曲线上点的核心方法, 同时可用于曲线细分.
* 三阶贝塞尔曲线是**应用最广泛**的形式, 覆盖字体设计、CSS 动画、SVG 路径等领域.
* 贝塞尔曲线的**凸包性**和**仿射不变性**使其在计算机图形学中极具实用价值.
* 对于需要**局部控制**的复杂形状, B 样条曲线是更优选择.
