== MurMurHash讲解

MurMurHash(**Mur Mur Hash**, 名称来源于其核心操作: **M**ultiply and **R**otate) 是一种**非加密型哈希函数**, 由 Austin Appleby 在 2008 年设计. 它以其**高速、良好的分布性、低碰撞率**以及对规律性键值(如连续数字)的强抗性而闻名, 特别适合基于哈希表(如哈希映射、布隆过滤器)和分布式系统(如分片)的应用.

=== 核心特点
非加密::
设计目标是**速度**和**分布均匀性**, **不是**安全性. 它不适合用于密码学目的(如消息认证、数字签名).

高性能::
在现代 CPU 上非常快(通常优于 MD5、SHA-1 等加密哈希, 甚至快于很多较简单的非加密哈希).

良好的雪崩效应::
输入的微小变化会导致输出哈希值发生巨大且不可预测的变化.

良好的分布性::
哈希值在输出空间(如 32 位或 64 位)中均匀分布, 即使对于有规律的输入(如递增序列)也是如此. 这减少了哈希碰撞的可能性.

种子化::
接受一个可选的 **seed** 值作为输入. 不同的种子会产生完全不同的哈希序列. 这非常有用:

* 防止针对特定哈希分布的 DoS 攻击(攻击者构造大量碰撞的键).
* 为同一键生成多个独立的哈希值(例如在布隆过滤器中).
* 在分布式系统中实现一致性哈希的变体.

变体::
最常见的是 MurMurHash3, 它提供 32 位和 128 位哈希输出.还有早期的 MurMurHash1 和 MurMurHash2(有多个子版本, 如 MurMurHash2A). **MurMurHash3 是目前最推荐使用的版本**.

=== 使用建议

优先使用 MurMurHash3::
它是目前最先进、最广泛使用的版本.

利用种子::
如果安全或需要多个哈希是考虑因素, 务必使用并管理好种子值.

使用标准库/成熟实现::
不要轻易自己实现. 使用语言的标准库(如 Python mmh3 包, Java Guava/Hutool, C++ Boost)或经过广泛验证的第三方库.

明确非加密性::
切勿将其用于需要密码学安全性的场景(如密码存储、数字签名、MAC). 在这些场景下, 应使用 SHA-2、SHA-3 或 BLAKE2/3 等.

=== 总结
MurMurHash(尤其是MurMurHash3)是一个在速度、分布质量和碰撞率之间取得极佳平衡的非加密哈希函数. 它在需要高性能哈希且不涉及密码学安全的场景中(如哈希表、布隆过滤器、分布式分片)是首选方案之一. 理解其核心操作(乘、旋转、异或)和种子化的价值对于有效使用它至关重要.
