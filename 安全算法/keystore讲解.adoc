== KeyStore讲解
KeyStore 是 Java 中用于**安全存储加密密钥和数字证书**的核心组件. 它提供了一个受密码保护的存储容器, 通常用于 TLS/SSL 加密、代码签名、数据加密等场景.

=== 存储内容
* 私钥(Private Key)及其关联的证书链
* 受信任的公钥证书(Trusted Certificates)
* 对称密钥(Secret Key)(仅限 JCEKS 类型)

=== 常见类型

|====
|类型|描述|文件扩展名

|JKS
|Java 默认格式(Java 9 前), 仅支持密钥和证书
|.jks

|PKCS12
|行业标准格式(Java 9+ 默认), 支持密钥、证书和对称密钥
|.p12/.pfx

|JCEKS
|增强版 JKS, 支持对称密钥(需 JCE 提供)
|.jceks

|====

=== 核心操作代码示例

.创建 KeyStore
[source, java, linenums]
----
KeyStore ks = KeyStore.getInstance("PKCS12"); // 指定类型
char[] password = "changeit".toCharArray();
ks.load(null, password); // 初始化空存储

// 保存到文件
try (FileOutputStream fos = new FileOutputStream("keystore.p12")) {
    ks.store(fos, password);
}
----

.加载 KeyStore
[source, java, linenums]
----
KeyStore ks = KeyStore.getInstance("PKCS12");
try (FileInputStream fis = new FileInputStream("keystore.p12")) {
    ks.load(fis, "changeit".toCharArray());
}
----

.添加私钥条目
[source, java, linenums]
----
// 生成密钥对(实际应从安全源获取)
KeyPairGenerator gen = KeyPairGenerator.getInstance("RSA");
gen.initialize(2048);
KeyPair keyPair = gen.generateKeyPair();

// 创建证书链(示例)
X509Certificate cert = generateSelfSignedCert(keyPair); // 需自定义证书生成

// 添加到 KeyStore
ks.setKeyEntry(
    "mykey",                      // 别名
    keyPair.getPrivate(),          // 私钥
    "keyPassword".toCharArray(),   // 密钥密码
    new Certificate[]{cert}        // 证书链
);
----

.添加信任证书
[source, java, linenums]
----
Certificate caCert = getCACertificate(); // 从外部获取CA证书
ks.setCertificateEntry("trustedCA", caCert); // 添加信任证书
----

.读取条目
[source, java, linenums]
----
// 读取私钥
PrivateKey privateKey = (PrivateKey) ks.getKey("mykey", "keyPassword".toCharArray());

// 读取证书链
Certificate[] chain = ks.getCertificateChain("mykey");

// 读取信任证书
Certificate cert = ks.getCertificate("trustedCA");
----

=== 典型应用场景

.SSL/TLS 服务器
[source, java, linenums]
----
SSLContext sslContext = SSLContext.getInstance("TLS");
KeyManagerFactory kmf = KeyManagerFactory.getInstance("PKIX");
kmf.init(ks, "keyPassword".toCharArray()); // 加载密钥库
sslContext.init(kmf.getKeyManagers(), null, null);
----

.SSL/TLS 客户端
[source, java, linenums]
----
TrustManagerFactory tmf = TrustManagerFactory.getInstance("PKIX");
tmf.init(ks); // 加载信任库
sslContext.init(null, tmf.getTrustManagers(), null);
----

.加密/解密数据
[source, java, linenums]
----
Cipher cipher = Cipher.getInstance("RSA");
cipher.init(Cipher.ENCRYPT_MODE, ks.getCertificate("trustedCA").getPublicKey());
byte[] encrypted = cipher.doFinal(data);
----

=== 命令行管理工具
使用 Java 自带的 **keytool**

[source, bash, linenums]
----
# 生成 JKS 密钥库
keytool -genkeypair -alias mykey -keyalg RSA -keystore keystore.jks

# 导出证书
keytool -exportcert -alias mykey -file cert.cer -keystore keystore.jks

# 查看存储内容
keytool -list -v -keystore keystore.jks
----

=== 最佳实践
密码安全::
* 避免硬编码密码, 使用安全配置服务
* 密钥密码 ≠ 存储密码(PKCS12 强制要求)

类型选择::
* 新项目优先使用 **PKCS12**(Java 9+ 默认)
* 需要存储对称密钥时用 **JCEKS**

文件保护::
* 设置文件系统权限(600)
* 避免版本控制提交密钥库

证书轮换::
通过别名管理不同版本的密钥

[source, java, linenums]
----
ks.setKeyEntry("mykey-2025", newPrivateKey, password, newChain);
----

注意::
KeyStore 不提供加密功能, 仅用于安全存储! 实际加密需通过 **Cipher** 等 API 实现.
