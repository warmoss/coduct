== Shor算法讲解

Shor算法是**首个展示量子计算指数级加速优势**的算法, 由 Peter Shor 在 1994 年提出. 它能在**多项式时间**内完成大整数的质因数分解——这是经典计算机上公认的难题. 这一发现直接威胁到 RSA 等主流公钥密码体制的安全性, 并极大推动了量子计算和**后量子密码学(Post-Quantum Cryptography, PQC)** 的发展.

=== 核心思想

Shor算法的核心思想是将大整数分解问题**归约**到**周期查找(Period Finding)** 问题, 再用量子计算高效求解周期.

. **经典部分:** 利用数论技巧, 将因子分解转换为求一个函数 **f(x) = a^x mod N** 的周期(阶).
. **量子部分:** 利用**量子傅里叶变换(Quantum Fourier Transform, QFT)** 对函数进行并行求值和干涉, 在多项式时间内测出周期.

这种"经典归约 + 量子加速"的范式, 是设计量子算法的重要模式.

==== 周期(阶)的定义

对于与 **N** 互质的整数 **a**, 存在最小的正整数 **r** 使得:

[stem]
++++
a^r -= 1 (mod N)
++++

这个 **r** 称为 **a** 模 **N** 的**阶(order)**, 也是函数 **f(x) = a^x mod N** 的**周期**.

例如: **N=15, a=7**:
* stem:[7^1 mod 15 = 7]
* stem:[7^2 mod 15 = 4]
* stem:[7^3 mod 15 = 13]
* stem:[7^4 mod 15 = 1] → 周期 **r = 4**

==== 从周期到因子

如果找到 **a** 模 **N** 的周期 **r**, 且 **r** 为偶数, 则:

[stem]
++++
a^r -= 1 (mod N)
(a^{r/2})^2 - 1 -= 0 (mod N)
(a^{r/2} - 1)(a^{r/2} + 1) -= 0 (mod N)
++++

这意味着 **N** 整除 **a^{r/2} - 1** 或 **a^{r/2} + 1**(或两者). 如果 **a^{r/2} not-= +-1 (mod N)**, 则 gcd(a^{r/2} - 1, N) 和 gcd(a^{r/2} + 1, N) 中至少有一个是 **N** 的非平凡因子.

=== 算法流程

Shor算法整体流程如下:

. 随机选择 **a**, 满足 **1 < a < N**.
. 计算 **d = gcd(a, N)**. 如果 **d > 1**, 则 **d** 就是因子, 算法结束.
. (量子部分) 用量子计算机求 **a** 模 **N** 的周期 **r**.
. 如果 **r** 为奇数, 回到步骤1 重新选 **a**.
. 如果 **a^{r/2} -= +-1 (mod N)**, 回到步骤1 重新选 **a**.
. 计算 **p = gcd(a^{r/2} - 1, N)** 和 **q = gcd(a^{r/2} + 1, N)**, 得到因子 **p** 和 **q**.

=== 量子周期查找(核心)

量子周期查找是 Shor 算法的核心突破. 它利用两个量子寄存器和一个量子电路实现:

==== 寄存器设置

. **寄存器 1(输入寄存器):** 存储 **t** 个量子比特, 其中 **t** 使得 **N^2 <= 2^t < 2N^2**. 用于表示输入值 **x**.
. **寄存器 2(输出寄存器):** 足够存储 **f(x) = a^x mod N** 的结果.

==== 执行步骤

. **初始化:** 将寄存器1 中的所有量子比特置于叠加态 **|0>**. +通过 Hadamard 门将所有量子比特变为均匀叠加态:
+
[stem]
++++
|psi_1> = 1/sqrt(2^t) sum_{x=0}^{2^t-1} |x>
++++

. **计算函数值:** 对寄存器1 中的每个 **x**, 并行计算 **f(x) = a^x mod N**, 结果存入寄存器2:
+
[stem]
++++
|psi_2> = 1/sqrt(2^t) sum_{x=0}^{2^t-1} |x> |a^x mod N>
++++

. **测量寄存器2:** 测量寄存器2, 得到某个值 **f0**. 这会使寄存器1 的态**坍缩**为所有使 **a^x mod N = f0** 的 **x** 的叠加. 因为这些 **x** 呈等差数列: **x0, x0+r, x0+2r, ...**, 所以寄存器1 变为:
+
[stem]
++++
|psi_3> = 1/sqrt(L) sum_{k=0}^{L-1} |x0 + k*r>
++++
+
其中 **L** 是满足 **x0 + k*r < 2^t** 的周期数.

. **应用量子傅里叶变换:** 对寄存器1 应用 QFT. QFT 将周期为 **r** 的序列变换为频率域上的尖峰, 尖峰位置接近 **j * 2^t / r** 的整数倍:
+
[stem]
++++
|psi_4> = QFT |psi_3>
++++

. **测量寄存器1:** 测量得到某个值 **y**. **y** 接近 **j * 2^t / r**, 其中 **j** 是 0 到 **r-1** 之间的随机整数.

. **计算周期:** 使用**连分数展开(Continued Fraction Expansion)** 从 **y / 2^t** 逼近出 **j / r**, 从而得到 **r**.

==== 为什么 QFT 能找出周期?

QFT 是经典离散傅里叶变换(DFT)的量子版本, 其核心公式为:

[stem]
++++
QFT |x> = 1/sqrt(M) sum_{k=0}^{M-1} e^{2 pi i x k / M} |k>
++++

当输入态包含周期为 **r** 的序列时, QFT 后的概率幅会在 **k ~ j*M/r** 处产生**相长干涉**, 在其他位置产生**相消干涉**. 因此测量结果大概率落在这些峰值附近.

=== 对RSA的威胁

RSA 的安全性直接依赖于大整数分解的计算难度. Shor 算法在理论上彻底打破了这一基石:

* RSA 模数 **N = p * q** 可在 **O((log N)^3)** 时间内被分解
* 一旦分解出 **p** 和 **q**, 即可计算 **φ(N) = (p-1)(q-1)**, 进而用公钥 **e** 求出私钥 **d**(即 **e** 在模 **φ(N)** 下的逆元)
* 这意味着**所有基于 RSA 的加密、签名和证书体系在量子计算机面前都将失效**

不仅仅 RSA, 其他依赖离散对数问题的密码体制也受到威胁:

|===
|密码体制|受威胁程度|依赖问题

|RSA
|**完全被攻破**
|大整数分解

|ECDSA / ECDH
|**完全被攻破**
|椭圆曲线离散对数

|DSA / Diffie-Hellman
|**完全被攻破**
|有限域离散对数

|AES (对称加密)
|**部分受威胁**(密钥长度需加倍)
|— (Grover 算法)

|SHA-2 / SHA-3 (哈希)
|**部分受威胁**(输出长度需加倍)
|— (Grover 算法)

|===

=== 现状与局限

==== 实验进展

目前 Shor 算法已在量子计算机上成功分解了 **15**(3x5, 2001年, IBM 7量子比特)、**21**(2012年) 和 **143**(虽然用了简化方法) 等小整数. 但分解 2048 位 RSA 密钥所需的量子比特数和纠错能力远超当前技术水平:

* 所需约 **几千个逻辑量子比特**(每个逻辑量子比特需要约 1000 个物理量子比特进行纠错)
* 当前最先进的量子处理器仅有约 100-1000 个**物理量子比特**

==== 关键局限

* **量子比特数量不足:** 分解 2048 位 RSA 密钥可能需要数百万个物理量子比特
* **量子纠错:** 实际运行需要容错量子计算, 目前仍处于早期阶段
* **连分数展开的精度:** 测量误差可能导致周期计算错误, 需多次运行取统计结果

尽管如此, 这些限制是**工程性**而非**理论性**的. "现在安全"(safe now) 策略——即攻击者可以先存储加密数据, 等到量子计算机成熟后再解密——已经对长期保密的数据构成了现实威胁.

=== 总结

Shor 算法是量子计算领域最具影响力的算法之一:

* 它证明了量子计算机可以在多项式时间内解决大整数分解问题
* 它直接威胁 RSA、ECDSA、Diffie-Hellman 等主流公钥密码体制
* 它的设计范式——"经典归约 + 量子周期查找"——启发了众多后续量子算法
* 虽然目前受限于量子硬件水平, 但**后量子密码学(PQC)**的标准化已成为业界共识(NIST 已发布相关标准)

**核心启示:** 对于需要长期安全性的系统, 应尽早规划向抗量子密码体制的迁移.
